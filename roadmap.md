# Nexus roadmap

## v0.1.0 — Foundation

- minimal CMake project
- Linux-buildable Core and module tests
- Linux-to-Windows cross-build with MinGW-w64
- startable Windows x64 `Nexus.exe`
- Win32 main window
- sidebar navigation
- Home module
- Settings module
- simple theme foundation

## v0.2.0 — Core

- lightweight module registry
- command system
- persistent settings
- recent items
- focused Core test coverage

## v0.3.0 — File Explorer

- browse folders
- display files
- open files with the Windows default application
- open supported files inside Nexus
- create a copy
- intelligent recent-files list

## v0.4.0 — Editor

- plain-text editing
- Markdown editing and viewing
- tabs
- open and save
- basic search

## Roadmap rules

- Implement the current milestone before expanding later milestones.
- Later work may be pulled forward only when the user explicitly requests it.
- Keep milestones small enough to build and verify locally.
